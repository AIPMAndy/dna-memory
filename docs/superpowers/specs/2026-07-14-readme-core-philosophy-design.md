# DNA Memory README 核心理念设计

## 目标

在中英文 README 的首屏介绍中恢复 DNA Memory 的核心定位：它不是一个单纯保存
对话的数据仓库，而是一个受人类大脑记忆形成机制启发的认知提炼系统。README 需要
同时具备鲜明的品牌表达和可核验的工程依据。

## 核心定位

中文主张：

> DNA Memory 不把“保存对话”视为“形成记忆”。它受人类大脑记忆机制启发，
> 把跨客户端的大量对话视为原始感知输入，通过信号提取、重要性与置信度加权、
> 认知分型、验证结晶、召回反馈和新旧认知替代，持续把数据抽象为可复用认知。

英文表达保持同一含义，使用 `biomimetically inspired cognitive memory system`，避免使用
`brain replica` 等无法由当前实现支持的表述。

## README 结构

在现有项目简介之后、核心边界或安全模型之前，新增“核心理念 / Core philosophy”章节。
章节由四部分组成：

1. 一段品牌宣言，说明原始对话、长期记忆和可复用认知的区别。
2. 一条从对话数据到长期认知的处理链路。
3. 一组与当前八种记忆类型一致的认知分型。
4. 三条工程边界，防止将仿生学启发误读为完整复刻人脑。

## 认知处理链路

README 使用以下流程表达系统价值：

```text
大量原始对话
  -> 有界采集与信号提取
  -> 重要性、置信度与使用反馈加权
  -> 认知分型
  -> 验证后结晶为长期认知
  -> 按当前任务召回
  -> useful / misleading 反馈与 supersedes 演化
```

该流程映射当前实现中的原生历史导入、候选提案、`importance`、`confidence`、
`memory_feedback`、Markdown 长期真源和 `supersedes`，不引入新的运行时行为。

## 认知分型

README 将现有八种类型组织为四组认知模型，底层类型名保持不变：

| 认知模型 | 现有类型 | 含义 |
|---|---|---|
| 个体倾向 | `preference` | 稳定偏好与协作习惯 |
| 事实与洞察 | `fact`, `insight` | 已验证事实与从事实中抽象出的认识 |
| 决策与状态 | `decision`, `project_state`, `open_loop` | 决策理由、当前状态和待闭环事项 |
| 程序与经验 | `workflow`, `error_lesson` | 可复用流程和经过验证的失败经验 |

这里的“模型”是工程上的认知分型，不宣称与神经科学中的工作记忆、情景记忆、
语义记忆或程序记忆一一对应。

## 工程边界

- 仿生学是设计启发，不是对人脑的完整模拟。
- 原始会话继续留在客户端；DNA Memory 保存来源指针、候选和验证后的认知结论。
- 系统价值不以保存量衡量，而以高质量认知的形成、召回和后续有效复用衡量。
